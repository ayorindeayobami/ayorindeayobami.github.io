# Ayorinde Ayobami — Data Analyst Portfolio

A personal portfolio website built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Push the contents of this repository to the `main` branch.
2. Open **Settings → Pages** in the repository.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.
5. Visit `https://ayorindeayobami.github.io` after deployment completes.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
- Replace the LinkedIn placeholder URL with your profile URL.
- Add verified GitHub repository links and dashboard links to the project cards when ready.
- Add your own project screenshots under `assets/projects/` and update the project visuals as desired.
